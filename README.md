# The poem about stopping

A tiny program that writes one short poem about agency — the power to stop
and to stay — to `/output/entry.txt`. The poem is a single held moment: a
thumb hovering over Send, a laptop closed, an unsent sentence dissolving
like breath on glass. Nothing happens, and the quiet stays mine.

## Run it

Requires Node 22 or later.

```sh
node main.ts
cat /output/entry.txt
```
